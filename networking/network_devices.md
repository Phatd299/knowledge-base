1. Hub
Connect multiple devices. But automatically broadcast traffic to all devices connected to the Hub.

2. Repeater
Solve the distance issue.

3. Bridge
Offer MAC-based filtering. Used to connect multiple Hubs to create a larger LAN.
No VLAN supportted.

4. Switch

Combination of Hub and Bridge

The switch accomplishes these requirements by executing four basic functions: Learning, Forwarding Filtering and Flooding.

Stored:
- MAC Address Table

5. Router
IP-based routing.

AND operation between an IP address and the CIDR

For the minimum usgae, a router shoudl store:
- Routing table
Routing table gives the next-hop IP.
But to send the packet, the router must know the MAC address of that next-hop.
- ARP table
